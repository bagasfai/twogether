# About and FAQ Pages Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship public `/about` and `/faq` pages whose English and Indonesian text admins edit from `/admin`.

**Architecture:** Two typed tables (`community_about` singleton, `faq_items`) with admin-only writes enforced by RLS and column grants. FAQ create, move and delete go through advisory-locked RPCs so ordering stays unique and gapless. Public pages read through an anon-safe DAL that returns single-language shapes. The admin editors are Server Action driven and sit on the existing `/admin` page.

**Tech Stack:** Next.js (App Router, `next-intl`), Supabase (Postgres, RLS, pgTAP), react-hook-form + zod, shadcn/ui, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-22-about-faq-design.md`

## Global Constraints

- AGENTS.md: this Next.js has breaking changes. Read the relevant guide in `node_modules/next/dist/docs/` before writing page, metadata or `revalidatePath` code.
- Locales are `id` (default) and `en`, `localePrefix: "as-needed"` (`i18n/routing.ts`). Public pages go under `app/[locale]/(marketing)/`. The `(app)` shell has no locale segment and no `NextIntlClientProvider`; the admin UI is English-only.
- Both `en` and `id` text are required on every entry, enforced by `not null` plus a non-blank check in the database and by zod in the app.
- Length caps (characters): About title 120, About body 8000, FAQ question 200, FAQ answer 4000.
- Plain text only, rendered with `whitespace-pre-wrap`. No HTML, no markdown.
- No publish/draft flag. Only admins write (hosts cannot). Everyone, including anonymous visitors, can read.
- `sort_order` changes only through RPCs. FAQ RPCs are `security definer`, `search_path = public, pg_temp`, check `public.is_admin()` inside (`JB007`), assert READ COMMITTED (`JB006`), and take `pg_advisory_xact_lock`. No new error codes: reuse `JB006`, `JB007`, `JB008` (not found), `JB011` (validation).
- Revalidate with the `[locale]` pattern form (`type: "page"`), as `lib/gallery/revalidate.ts` does.
- Header nav must not scroll horizontally at 320px (comment in `app/[locale]/(marketing)/layout.tsx`).
- Touch targets in the editors are at least 44px (`h-11`).
- Migration filename: `supabase/migrations/20261022000001_about_faq.sql` and, if split, `20261022000002_faq_rpcs.sql`. pgTAP files continue the numbering: `028_*`, `029_*`.
- After every schema change, regenerate types: `npx supabase gen types typescript --local > types/supabase.ts`.
- Never skip commit hooks. Commit after every task.

## Review Focus

Inputs and conditions the spec implies but does not spell out. Each line has its pinning test in the task named.

1. FAQ answer or question containing `</script>` or `<` makes the page's JSON-LD break out of its tag. Expected: escaped, page stays valid. (Task 3, Task 4)
2. Windows-pasted text with `\r\n` line breaks and leading or trailing whitespace. Expected: trimmed, stored and shown with line breaks intact. (Task 3)
3. A stale admin page clicks Move up on the first item, or Move on a deleted item. Expected: edge is a silent no-op, unknown id is `not_found`, order stays valid. (Task 2, Task 5)
4. The About row is missing (removed out of band) or the FAQ is empty. Expected: both public pages render an empty state, never a 500. (Task 3, Task 4)
5. An unknown locale reaches the DAL (for example `fr`). Expected: falls back to `id`, the default locale. (Task 3)

### Task 2: FAQ ordering RPCs and concurrency proof

**Files:**
- Create: `supabase/migrations/20261022000002_faq_rpcs.sql`
- Create: `supabase/tests/029_faq_rpcs.test.sql`
- Create: `scripts/test-concurrent-faq-order.sh`

**Interfaces:**
- Consumes: Task 1 tables and `public.faq_lock_key()`.
- Produces: `public.faq_create(p_question_en text, p_question_id text, p_answer_en text, p_answer_id text) returns uuid`, `public.faq_move(p_id uuid, p_direction text) returns void`, `public.faq_delete(p_id uuid) returns void`. Execute is revoked from `public, anon` and granted to `authenticated`. Behavior: `faq_create` appends at `coalesce(max(sort_order), 0) + 1`; `faq_move` swaps with the neighbour and no-ops at an edge; `faq_delete` removes the row then decrements every higher `sort_order` by one. Errors: non-admin `JB007`, wrong isolation `JB006`, unknown id `JB008`, direction other than `'up'`/`'down'` `JB011`. Blank or over-length text surfaces as the table's check violation `23514`.

- [ ] **Step 1: Write `029_faq_rpcs.test.sql` (failing).** Assertions:

  - after `faq_delete(middle)`, remaining positions are exactly 1, 2 (gapless) and the deleted id is gone;
  - `faq_move` and `faq_delete` on a random uuid raise `JB008`; `faq_move(x, 'sideways')` raises `JB011`;
  - member, host and `anon` calling each of the three RPCs get `JB007` (anon: privilege error, `42501`);
  - `faq_create` with a blank answer raises `23514`;
  - calling an RPC inside `set transaction isolation level repeatable read` raises `JB006`.
